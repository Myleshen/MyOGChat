# Phase 2.4 — Tools: web search + extensible agentic loop

Status: implemented on branch `feat/tools` (worktree `myogchat-wt/tools`).

## Goal

Let the model call tools. The model requests a tool, the server executes it,
feeds the result back, and repeats until the model produces a final answer —
bounded to avoid runaway loops.

## Tool framework (`internal/tools`)

A normalized interface plus an ordered, per-request registry:

```go
type Tool interface {
    Name() string
    Description() string
    Parameters() json.RawMessage              // JSON-schema object
    Run(ctx context.Context, args json.RawMessage) (string, error)
}

type Registry struct{ /* ordered map */ }
func (r *Registry) Add(t Tool)                 // replace by name, keep order
func (r *Registry) Get(name string) (Tool, bool)
func (r *Registry) Specs() []Spec              // {Name, Description, Parameters}
```

A fresh registry is built per chat request (`Server.toolRegistry`) so tools that
depend on settings (Linkwarden) are isolated. `tools.DecodeArgs` tolerates
missing/`null` arguments as `{}`.

### Built-in tools

| tool | source | notes |
|---|---|---|
| `web_search(query)` | Tavily | `POST https://api.tavily.com/search`, Bearer `TAVILY_API_KEY`, top 5 results as `title — url\nsnippet`. Only registered when the key is set. |
| `fetch_url(url)` | direct HTTP | GET → readable text (HTML stripped). Powers URL summarization (see `2.8-linkwarden.md`). SSRF-guarded. |
| `linkwarden_search(query)` | Linkwarden | see `2.8-linkwarden.md`. |
| `linkwarden_save(url, title?)` | Linkwarden | see `2.8-linkwarden.md`. |

`fetch_url` refuses to dial loopback, private, link-local, multicast, or
carrier-grade-NAT addresses. The check runs at dial time on the resolved IP
(`net.Dialer.Control`), which also defends against DNS rebinding.

## Agentic loop (`internal/upstream/agent.go`)

`Client.StreamAgent(ctx, Params, ExecuteTool) <-chan Event` streams the reply,
runs requested tools, and repeats. It emits the same normalized events as
`Stream` plus `EventTool`, and one aggregated `EventUsage` at the end (tokens
summed across rounds) so cost accounting covers the whole turn. The loop is
bounded to `maxToolIterations = 4`.

```go
type ExecuteTool func(ctx context.Context, call ToolCall) (result, summary string, err error)
type ToolCall struct { ID, ItemID, Name, Arguments string }
```

### Chat dialect

- Sends `tools` + `tool_choice: "auto"`.
- Accumulates streamed `choices[0].delta.tool_calls` fragments by `index`
  (`chatToolAccumulator`).
- On the round end, if any calls were assembled: appends an assistant
  `tool_calls` message, executes each call, appends a `role:"tool"` result
  message, and streams again.
- If a model rejects tools outright on the first round, the request is retried
  once without `tools` so the chat still works.

### Responses dialect

- Sends flattened `tools` (`{type:"function", name, description, parameters}`).
- Handles `response.output_item.added`, `response.function_call_arguments.delta`,
  `response.function_call_arguments.done`, `response.output_item.done`, and the
  authoritative function-call items in `response.completed`
  (`responsesToolAccumulator`).
- Executes calls, then continues the input with `function_call` and
  `function_call_output` items.

## SSE additions (`internal/server/chat.go`)

The wire format is unchanged and backwards compatible. A new event is added:

| event | data JSON | when |
|---|---|---|
| `tool` | `{"name":"web_search","status":"running"\|"done"\|"error","summary":"…"}` | around each tool execution |

## Configuration

- `TAVILY_API_KEY` — enables `web_search` (optional). Read once at startup and
  passed to `server.New`.
- Admin settings (global, via `GET|PATCH /api/settings`):
  - `tools_enabled` (bool, default **on**) — master switch for tool calling.
  - `tavily_configured` (read-only bool) — whether the env key is present.

## Frontend

- Streaming renders a compact tool-activity line inside the assistant bubble
  (`🔧 web_search · done`, `⏳ … · running`, `⚠️ … · error`), kept on the
  in-memory message for the session.
- Settings → **Integrations** (admins): tools toggle, Tavily status, Linkwarden
  fields (see `2.8-linkwarden.md`).
- Service worker cache bumped (`myogchat-shell-v7`).
