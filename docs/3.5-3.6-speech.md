# 3.5 STT + 3.6 TTS — Voice for MyOGChat

Voice input (speech-to-text) and spoken replies (text-to-speech), backed by
**persistent HTTP services** — *not* Ollama, which serves LLMs and embeddings
only and has no audio endpoints. Full rationale and hardware numbers:
`docs/research/3.5-3.6-tts-stt.md`.

```
browser ──▶ Go (Pi) ──▶ internal/speech ──▶ [ whisper.cpp / Piper on the Pi
 MediaRecorder / <audio>                      OR an OpenAI-compatible GPU shim ]
```

Whisper and Piper are native runtimes that cannot be cgo-linked into the
`CGO_ENABLED=0` single binary. Like `internal/ocr`, they run as **separate
servers**; unlike OCR they are **persistent** (the model stays warm), so the Go
side calls them over HTTP rather than `docker run` per request. The wire format
stays **OpenAI-compatible** so a local `whisper-server`/Piper server, a Proxmox
GPU shim (faster-whisper + Kokoro), or the hosted OpenAI audio APIs are all
drop-in.

## The `internal/speech` package

Two interfaces, mirroring `internal/ocr`'s engine seam:

```go
type Transcriber interface {
    Transcribe(ctx context.Context, audio []byte, filename, mime string) (string, error)
}
type Synthesizer interface {
    Synthesize(ctx context.Context, text, voice string) ([]byte, string, error) // audio, mime
}
```

Backends:

- `OpenAISTT` — `POST /v1/audio/transcriptions` (multipart `file` + `model` +
  optional `language` + `response_format=json`) → `{"text": "…"}`. Works with
  `whisper.cpp`'s `whisper-server`, `speaches`, or OpenAI.
- `OpenAITTS` — `POST /v1/audio/speech` (JSON `model`/`input`/`voice`/
  `response_format=wav`) → WAV bytes. The default; a drop-in for a GPU/OpenAI
  shim.
- `PiperTTS` — the native `piper.http_server` shape (`POST /` with `{"text":…}`)
  → WAV. Selected with `MYOGCHAT_TTS_FORMAT=piper`.

`STTFunc`/`TTSFunc` adapt an engine to a plain function bound to a context
(the same shape as `ocr.OCRFunc`), so the engines can be reused elsewhere.

Sentinel errors (`ErrUnavailable`, `ErrEmptyAudio`, `ErrEmptyText`) let the HTTP
layer map failures to statuses.

## HTTP endpoints

Both require a session (per-user, like every other `/api/*` route).

### `POST /api/stt`

`multipart/form-data` with an **`audio`** field (the generic `file` field is also
accepted) and an optional **`language`** field. Limits: **25 MB** and a
non-empty body; the MIME is taken from the part or sniffed.

- `200 {"text":"…","duration_ms":N}` on success (text trimmed).
- `400` missing/empty audio or a malformed upload.
- `413` over 25 MB.
- `503` when STT is disabled or unconfigured; the service being unreachable is
  also `503`; any other engine failure is `502`.

### `POST /api/tts`

JSON `{"text":"…","voice"?:"…"}` (a `format` field is accepted and ignored; the
output is always the service's native audio type, WAV for Piper/OpenAI).

- `200` raw audio bytes (`Content-Type: audio/wav`, `Cache-Control: no-store`).
- `400` empty text, or text over **4000 characters**.
- `503` when TTS is disabled or unconfigured, or the service is unreachable.
- `502` any other engine failure.

### `GET /api/speech/status`

Any signed-in user. `{"stt_available","stt_enabled","tts_available","tts_enabled","tts_voice"}`
— the composer reads this to show/hide the mic and speak buttons.

## Configuration

Env (read at startup):

| Env | Default | Notes |
|---|---|---|
| `MYOGCHAT_STT` | `auto` | `off` disables STT (URL cleared) |
| `MYOGCHAT_STT_URL` | `http://127.0.0.1:8080` | whisper.cpp `whisper-server` or a shim |
| `MYOGCHAT_STT_MODEL` | `base.en` | informational / passed through |
| `MYOGCHAT_STT_LANGUAGE` | *(blank)* | optional ISO-639-1 hint (`en`) |
| `MYOGCHAT_STT_TIMEOUT` | `120s` | accepts `120s` or a bare number of seconds |
| `MYOGCHAT_STT_KEY` | *(blank)* | optional `Authorization: Bearer` for a shim |
| `MYOGCHAT_TTS` | `auto` | `off` disables TTS (URL cleared) |
| `MYOGCHAT_TTS_URL` | `http://127.0.0.1:5000` | Piper or an OpenAI-compatible shim |
| `MYOGCHAT_TTS_VOICE` | `en_US-lessac-medium` | default voice |
| `MYOGCHAT_TTS_FORMAT` | `openai` | `openai` \| `piper` |
| `MYOGCHAT_TTS_MODEL` | `tts-1` | OpenAI speech model (ignored by Piper) |
| `MYOGCHAT_TTS_TIMEOUT` | `30s` | |
| `MYOGCHAT_TTS_KEY` | *(blank)* | optional bearer token for a shim |

DB settings (admin, editable live in Settings — no restart):

- `stt_enabled`, `tts_enabled` (default `true`) — the toggles.
- `stt_url`, `tts_url`, `tts_voice` — overrides of the env defaults (blank falls
  back to the env value).

They are surfaced by `GET /api/settings` as
`stt_enabled`, `stt_available`, `stt_url`, `tts_enabled`, `tts_available`,
`tts_url`, `tts_voice`, and set by `PATCH /api/settings` (see
`API_CONTRACT.md` §11).

## Frontend

- **Mic button** (`#mic-btn`) in the composer: `getUserMedia` + `MediaRecorder`
  (webm/opus on Chromium/Firefox, mp4/AAC on Safari/iOS), uploads to
  `/api/stt`, and **appends** the transcript to the composer (never clobbers
  what is typed). States: idle → recording (pulsing red) → transcribing. Handles
  permission denial, and falls back to a hidden `accept="audio/*"` file input
  when `MediaRecorder` is unavailable. The button is hidden unless STT is
  available + enabled, and disabled while a reply streams.
- **Speak button** on every assistant message (in `.msg-actions`): strips
  markdown/code with `plainTextForSpeech`, fetches `/api/tts`, and plays the WAV
  via `new Audio(URL.createObjectURL(blob))`. The blob is cached per message id;
  the button toggles Speak/Stop. When no server TTS is configured it falls back
  to the on-device **Web Speech API** (`window.speechSynthesis`).
- **Settings → Voice** (admin): enable toggles, STT/TTS URLs, default voice, and
  a status line. Self-contained block (`#voice-section`), safe to relocate.
- `static/sw.js` cache bumped to `myogchat-shell-v9`.

## Provisioning

Pi-local default (persistent containers on loopback):

```sh
bash deploy/speech-setup.sh
#   STT: ghcr.io/ggml-org/whisper.cpp:main  → 127.0.0.1:8080 (base.en)
#   TTS: myogchat-piper (deploy/speech/piper) → 127.0.0.1:5000 (en_US-lessac-medium)
```

Then set (already the defaults) in `~/.config/myogchat/env`:

```
MYOGCHAT_STT_URL=http://127.0.0.1:8080
MYOGCHAT_TTS_URL=http://127.0.0.1:5000
```

**Proxmox GPU option:** run faster-whisper (`large-v3` int8) + Kokoro behind an
OpenAI-compatible shim, LAN-only, and point `MYOGCHAT_STT_URL`/`MYOGCHAT_TTS_URL`
at it. Never expose the shim through the Cloudflare Tunnel — the Pi reaches it
over the LAN.

## Tests

- `internal/speech/speech_test.go` — `httptest` fake servers assert the STT
  multipart shape (path, fields, file part, audio bytes) and the TTS JSON shapes
  (OpenAI and Piper), plus empty-input, non-2xx, unreachable, and timeout paths.
- `internal/server/speech_test.go` — fake `Transcriber`/`Synthesizer` engines
  exercise the handlers: multipart success, missing audio, disabled/unconfigured
  → `503`, TTS success (bytes + `audio/wav`), empty/too-long text → `400`,
  unreachable → `503`, URL/voice overrides, and the settings/status payloads.
